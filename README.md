# 1996 義守大學（高雄工學院時期）3D 實景地圖

依 1996–1997 年校史館與校友實景老照片、`1996年義守大學平面圖` 及觀音山東麓地形重建之互動式 WebGL 3D 實景地圖（Three.js）。

## 線上預覽
- GitHub Pages: https://spencer384.github.io/isu-1996-3d-map/

## 1996 年歷史還原重點
- **校門口與精神指標**：直書「高雄工學院」紅磚校門塔樓、紅色伸縮大門、銀色雙環精神指標、高雄客運黃紅雙色校車與北側球場。
- **核心建築群**：泳池（1995 年啟用，含萬國旗與看台）、活動中心（含圓形噴水池與玻璃三角採光罩）、口字型教學大樓、紅色舊水塔（八角校徽槽體與 X 型鋼架）、125 階長樓梯（百階）、行政大樓（綜合大樓，中央弧形玻璃帷幕與白色尖塔）、科技大樓（1995 圓柱轉角塔樓）、義守大學圖書館。
- **1996 年男女宿配置**：高層 11 樓雙棟為**男宿**（附 6 樓通往操場側天橋、路邊 26 輛機車陣），西側 4 樓低層紅瓦四合院為**女宿**（含一樓學生餐廳遮雨棚）；註明於 1997 年對調。
- **後方操場與校慶拔河**：升旗台與 5 層觀眾席位於操場南側（面向北方），草皮內場重現 1996/10/16 高雄工學院校慶拔河比賽。

## 操作方式
- **左鍵拖曳**：水平移動地圖
- **右鍵拖曳**：旋轉視角
- **滾輪**：縮放遠近
- **第一人稱漫步**：點擊「第一人稱漫步」後使用 `W A S D` 移動、`Shift` 加速
- **視角與光影**：支援「1996 全景視角」、「平面圖俯視（正北朝上）」及 4 種時段光影（晴朗白天、午後山嵐、黃昏夕照、校園夜景）
