# 1996 義守大學（高雄工學院時期）3D 實景地圖

依 1996–1997 年校史館與校友實景老照片、`1996年義守大學平面圖` 及觀音山東麓地形重建之互動式 WebGL 3D 實景地圖（Three.js）。

## 線上預覽
- GitHub Pages: https://spencer384.github.io/isu-1996-3d-map/

## 1996 年歷史還原重點
- **校門口與精神指標**：直書「高雄工學院」紅磚校門塔樓、紅色伸縮大門、銀色雙環精神指標、高雄客運黃紅雙色校車與北側球場。
- **核心建築群**：泳池（1995 年啟用，含萬國旗與看台）、活動中心（含圓形噴水池與玻璃三角採光罩）、口字型教學大樓、紅色舊水塔（八角校徽槽體與 X 型鋼架）、125 階長樓梯（百階）、行政大樓（綜合大樓，中央弧形玻璃帷幕與白色尖塔）、科技大樓（1995 圓柱轉角塔樓）、義守大學圖書館。
- **1996 年男女宿配置**：高層 11 樓雙棟為**男宿**（附 6 樓通往操場側天橋、路邊 26 輛機車陣），西側 4 樓低層紅瓦四合院為**女宿**（含一樓學生餐廳遮雨棚）；註明於 1997 年對調。
- **後方操場與校慶拔河**：升旗台與 5 層觀眾席位於操場南側（面向北方），草皮內場重現 1996/10/16 高雄工學院校慶拔河比賽。

## 操作方式
- **PC 滑鼠**：左鍵拖曳水平移動、右鍵拖曳旋轉視角、滾輪縮放遠近
- **手機觸控**：單指拖曳水平移動、雙指捏合與滑動縮放／旋轉視角
- **第一人稱漫步**：PC 使用 `W A S D` 移動、`Shift` 加速；手機支援單指滑動轉動視角與左下角虛擬方向鍵移動
- **4D 時空與光影**：支援 1993／1996／1997／2001／2026 現況年份切換（含分享網址 `?era=`）、4 種時段光影（晴朗白天、午後山嵐、黃昏夕照、校園夜景）及「平面圖俯視（正北朝上）」

## 2026 年現況 3D 重建重點（依 Google 地球最新 3D 實景）
- **管理學院大樓**：中央山坡台階地多層紅磚歇山大屋頂建築群，含迎賓門廊、連通步道與綠意庭園。
- **星座廣場**：替代 1996 舊水塔山坡，重建為中央金藍天球渾天儀、星象羅盤圖騰鋪面、依山就勢的半圓形階梯花園看台與常綠柏樹景觀。
- **觀光餐旅學院大樓**：坐落於上層平台操場西側與管理學院上方，擁有景觀露台與經典紅磚紅瓦外觀。
- **材料科學工程系與國際學院**：科技大樓旁擴建棟，含現代化實驗室排風設施、光電板與連通空橋。
- **學生宿舍群擴建**：西側山坡第一、第二學生宿舍群，多翼層疊依山而建，由空中廊道連通上層平台。
- **現代化運動場與校門**：400m 全天候合成跑道、北側現代數位計分塔、現代校門警衛中心與迎賓廣場。

## 類似 3D 實景地圖專案的設計步驟與提示詞建議

### 一、標準設計 6 步驟
1. **先定「2D 底圖座標網格」與比例尺（最重要）**
   - 先提供一張**正北朝上的空拍圖或平面圖**，加上座標網格、定出原點 `(0, 0)` 與比例尺（例如 `1 px = 0.56 m`）。
   - 先在俯視圖／小地圖確認所有建築中心 `(X, Z)`、旋轉角度、道路路線與樓梯起終點後，再開始 3D 建模。
2. **先畫「垂直高程分層表（Height Tiers）」與斜坡關係**
   - 明確定義哪些建築位於**同一高程平面**（如本案行政大樓、科技大樓、圖書館、操場統一位於 `33.5m`），以及高低落差處的連接方式（如男宿 1F `19.5m` 與操場 `33.5m` 之間為 1F→6F 山坡，由 6 樓連結橋水平直通）。
3. **先做「白模（Greybox）＋道路防撞檢查」，再貼材質與細節**
   - 先用方塊佔位與道路中心線確認「建築不壓道路、平台斜坡邊緣不頂起路面、樹木路燈不長在車道上」，再加入紅磚貼圖、玻璃帷幕、機車與路燈等細節。
4. **開案即定義「PC／手機雙端 UI 與觸控規範」**
   - **PC（`> 900px`）**：固定側邊導覽欄＋完整說明卡＋小地圖。
   - **手機（`<= 900px`）**：標題精簡、單行橫向工具列、底部抽屜式導覽（選完自動收起）、小地圖可開關、3D 標籤防重疊過濾。
   - **觸控手勢**：明確指定（如單指平移、雙指縮放＋旋轉；漫步模式改為單指轉視角＋虛擬方向鍵）。
5. **若有時間軸（4D），先定「狀態切換矩陣」**
   - 用表格列出各年份顯示／隱藏的建築、貼圖與標籤變化，避免後續迭代時互相覆蓋。
6. **設定「線上預覽與防快取流程」**
   - 透過 GitHub Pages 線上預覽，每次更新 ES Module 時自動加上版本參數（`?v=...`），避免手機瀏覽器快取舊版程式。

### 二、給使用者的下提示詞（Prompt）建議
- **圖文並用**：在空拍圖或截圖上直接**圈選同高程區域、畫箭頭標註方向與連接點**，能大幅降低位置誤差。
- **說清楚相對關係**：例如「男宿東側與行政大樓之間還有一條路」、「操場高度在男宿 6 樓，兩者間為 1F→6F 山坡」。
- **整合時提醒保留既有功能**：多人／多輪修改時可提醒「請先同步遠端最新提交並保留既有功能（如 4D 時間軸）」。

#### 可直接套用的開案提示詞範本
> 「我想做一個互動式 3D 實景地圖，附上空拍底圖與標註：
> 1. 請先依底圖建立俯視座標與各區高程分層表（標出哪些區域同高、哪些有斜坡或天橋連接），先做白模與道路網讓我確認位置，確認後再做建築細節與貼圖。
> 2. 介面需同時適配 PC 與手機：手機版預設收起導覽為底部抽屜、單行工具列、標籤防重疊，觸控為單指移動、雙指縮放旋轉。
> 3. 每次更新請自動加上模組版本參數避免瀏覽器快取，確認後再推上 GitHub Pages。」
